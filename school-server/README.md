# school-server

البداية الأولى لسيرفر المنصة باستخدام Cloudflare Workers وCloudflare D1.

## يحتوي على
- `src/index.js`: API للتلاميذ، الأستاذ، الأفواج والاشتراكات.
- `schema.sql`: جداول قاعدة البيانات مع بيانات الأستاذ بومدين والأفواج الخمسة.
- `wrangler.jsonc`: إعدادات Worker وربط D1.
- `package.json`: أوامر التطوير والنشر.

## المتطلبات
- Node.js حديث
- حساب Cloudflare
- تثبيت Git وGitHub CLI (اختياري)

## التشغيل محلياً
```bash
npm install
npx wrangler login
npm run db:init:local
npm run dev
```

## إنشاء قاعدة D1 ونشر المخطط
```bash
npm run db:create
```
انسخ `database_id` الذي يظهر في الطرفية وضعه في `wrangler.jsonc` مكان `PUT_YOUR_D1_DATABASE_ID_HERE`، ثم:
```bash
npm run db:init:remote
```

## نشر Worker
```bash
npm run deploy
```
ضع نطاقات Cloudflare Pages الفعلية في `ALLOWED_ORIGINS` قبل النشر.

## API الحالية
- `GET /api/health`
- `GET /api/teachers`
- `GET /api/groups`
- `POST /api/students` إنشاء ملف تلميذ وإرجاع access token
- `GET /api/me` بيانات التلميذ الحالي (Bearer token)
- `GET /api/bookings` اشتراكات التلميذ (Bearer token)
- `POST /api/bookings` تسجيل تلميذ في فوج وتاريخ حصة (Bearer token)

مثال إنشاء تلميذ:
```json
{"first_name":"أحمد","last_name":"بن علي","age":16}
```

مثال اشتراك:
```json
{"group_id":1,"session_date":"2026-11-20"}
```

## قواعد التسجيل
يُسمح لكل حساب تلميذ بثلاثة تسجيلات ناجحة كحد أقصى في الأفواج خلال اليوم الواحد بتوقيت الجزائر (`Africa/Algiers`). يعاد الحد تلقائياً عند بداية اليوم التالي. لا يُحتسب التسجيل المكرر في الفوج نفسه والتاريخ نفسه، ولا يستهلك محاولة. يُفرض الحد داخل D1 وCloudflare Worker وليس في الواجهة فقط. إنشاء حساب التلميذ غير محدود بهذا الشرط.

السيرفر هو الذي يتحقق من توقيت `Africa/Algiers`، وأن الطلب يقع يوم الجمعة أو السبت بين 07:30 و16:00، وأن تاريخ الحصة يطابق يوم الفوج، وأن الحصة لم تبدأ بعد إذا كانت في اليوم نفسه. لا توجد حدود لعدد التلاميذ في الفوج. تمنع قاعدة البيانات تكرار اشتراك التلميذ في الفوج نفسه والتاريخ نفسه.

## مهم قبل الاستخدام الحقيقي
1. نموذج إنشاء التلميذ الحالي لا يثبت هوية الشخص لأنه لا يجمع كلمة مرور أو رقم هاتف أو بريد. رمز الدخول السري يُعاد مرة واحدة؛ فقدانه يعني عدم القدرة على استعادة الحساب. أضف وسيلة تحقق/استعادة قبل الإطلاق العام.
2. أضف حماية من الإساءة ومعدل طلبات (Cloudflare Rate Limiting/Turnstile) إلى إنشاء الحساب والاشتراكات.
3. لا تعتمد على `localStorage` كهوية؛ اربط واجهة التلميذ بالـ API وخزّن الرمز بعناية.
4. واجهات إدارة الأستاذ والدفع غير موجودة بعد. يجب حماية كل مسارات الإدارة بمصادقة وصلاحيات منفصلة قبل إضافتها.
5. الإشعارات المجدولة والتذكير قبل 30 دقيقة وتقييم ما بعد الحصة تحتاج جدول حصص/جدولة وإرسال Push أو قناة إشعار؛ لم تُنفذ في هذا الإصدار.
6. لا تعتبر الاشتراك دليلاً على الدفع. الدفع يبقى `unpaid` إلى أن تؤكده الإدارة لاحقاً.

## تحديثات الإصدار المحسّن

- مصادقة مستقلة للإدارة والأساتذة باستخدام جلسات Bearer مخزنة بصيغة hash في D1.
- حماية مسارات `/api/admin/*` و`/api/teacher/*`.
- إضافة أستاذ وكلمة مروره من لوحة الإدارة.
- إضافة الأفواج للإدارة أو للأستاذ صاحب الجلسة فقط.
- ملخص مالي إجمالي للإدارة وملخص مستقل لكل أستاذ.
- إشعارات إدارية داخل فضاء التلميذ.
- حد أقصى 3 تسجيلات ناجحة في الأفواج لكل حساب تلميذ يومياً بحسب توقيت الجزائر؛ لا يوجد حد يومي لإنشاء الحسابات.
- إضافة صفحة `teacher.html` لإدارة الأستاذ.

## ترقية قاعدة البيانات الحالية

إذا كنت تستخدم الحزمة المحسّنة السابقة وقد طبّقت ترقية `0002` بالفعل، نفّذ ترقية حد الأفواج الجديدة فقط مرة واحدة:
```bash
npm run db:migrate:daily-limit
```
إذا كنت ما زلت على قاعدة الإصدار الأصلي ولم تطبق `0002`، طبّق `0002` أولاً ثم `0003`:
```bash
npx wrangler d1 execute school-db --remote --file=./migrations/0002_auth_teachers_notifications.sql
npm run db:migrate:daily-limit
```
لا تنفّذ ملفات الترقية على قاعدة جديدة أنشأتها بالكامل من `schema.sql`؛ فهذا المخطط يحتوي الجداول والأعمدة المطلوبة مسبقاً.

## أسرار Cloudflare المطلوبة

من مجلد `school-server` نفّذ الأوامر التالية، وأدخل القيم عند الطلب:
```bash
npx wrangler secret put ADMIN_PASSWORD
npx wrangler secret put BOUMDIENE_INITIAL_PASSWORD
npx wrangler secret put RATE_LIMIT_SECRET
```
- `ADMIN_PASSWORD`: رمز دخول الإدارة. يمكنك إدخال `13` كما طلبت، لكنه قصير جداً ولا يُنصح به لحماية بيانات حقيقية.
- `BOUMDIENE_INITIAL_PASSWORD`: كلمة المرور الأولية للأستاذ بومدين. يمكنك إدخال `15` كما طلبت؛ بعد أول دخول تُحفظ بصمة كلمة المرور في D1.
- `RATE_LIMIT_SECRET`: قيمة عشوائية طويلة تستخدم لحماية حد محاولات تسجيل دخول الإدارة والأساتذة. لم يعد عنوان IP يحدد عدد تسجيلات التلميذ في الأفواج.

بعد تنفيذ الترقية وضبط الأسرار، انشر Worker:
```bash
npm run deploy
```

## روابط الواجهات
- الإدارة: `index.html` في مشروع admin-platform.
- الأستاذ: `teacher.html` في مشروع admin-platform.
- التلميذ: `index.html` في مشروع student-platform.

صفحة الأستاذ واحدة ديناميكية؛ يدخل كل أستاذ بمعرّفه وكلمة مروره، ثم لا يرى إلا أفواجه وبياناته. معرّف الأستاذ الجديد يظهر بعد إنشائه من لوحة الإدارة.

## حدود الإشعارات الحالية
الإشعارات الإدارية تُحفظ في D1 وتظهر للتلميذ داخل المنصة. تذكير الحصة قبل 30 دقيقة يعمل محلياً عندما تكون صفحة التلميذ مفتوحة ومسموحاً بإشعارات المتصفح. وصول الإشعار بعد إغلاق الموقع يتطلب استكمال Web Push (VAPID + Service Worker + جدولة Cloudflare)، وهو غير مفعّل في هذه الحزمة.
